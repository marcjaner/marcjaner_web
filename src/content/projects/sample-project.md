This page is illustrative sample content shipped with the project journal feature — it
demonstrates what a project overview looks like and is not a real thing I am building.

## Why this project

The idea it is standing in for is a small reading notebook: a place to write down what I
read — articles, papers, the occasional book — and the two or three thoughts each piece
left behind. Not a review site, not a feed, just notes I can find again.

## Where it stands

In this example the project is early: a list of entries, a page each, and a journal for
thinking out loud about how it should evolve. The point of the sample is to show the
shape — an overview that stays current plus dated journal entries underneath — without
pretending there is a product here yet.
